# conseptos vasicos  a javascript 

## variables
es como una caja magica q guarda informacion la cual puede cambiar como la edad
el puntaje de un juego o el color de ropa
## strings
es un dato q se usa en programacion q consiste en letras y numeros 
## funciones 
es una maquina magica o una regla especial q toma algo de entrada (x) le hace un cambio
y saca un resultado unico (y)
## if 
if significa si esto se usa para conectar  una causa con un resultado:si hace algo
(causa) entonses para otra hace consecuencia 
## booleanos
son como un interruptor de luz :solo puede estar encendido verdadero (true) o apagado (false)
